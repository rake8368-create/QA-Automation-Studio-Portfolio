# 테스트 설계

| 기법 | TC | 검증 입력 및 기대값 |
| --- | --- | --- |
| 경계값 | `PRO-002` | 프로파일 이름 1·50·51자. 1·50자는 허용하고 51자는 거부합니다. |
| 결정 테이블 | `MAC-003` | 매크로 OFF에서 F3. 입력 0회와 엔진 정지를 기대합니다. |
| 상태 전이 | `MAC-001` | 기본 설정으로 최초 실행. 매크로 OFF, 단축키 감시 비활성, 입력 없음이 기대값입니다. |
| 동등 분할 | `AUD-002` | 사용자 정의 분·초 값으로 3분 59초를 적용합니다. 변수 누락이나 문자열 오염 없이 치환돼야 합니다. |
