# 증적 무결성과 공개 사본

1. Run ID에 연결한 원본 JSON의 SHA-256을 SQLite 등록값과 대조합니다.
2. 패키지에 복사할 때 원본과 사본의 해시를 비교하고 확인 상태를 JSON 인덱스에 기록합니다.
3. 공개용 JSON은 관찰값·판정·Run ID·트리거 정보를 보존한 비식별 사본입니다. 로컬 경로, 명령줄, 프로세스·창·문서 식별자, 환경 세부 정보, 자유 형식 로그는 제외했습니다.
4. [증적 인덱스](../reports/submission-evidence/INDEX.md)에서 원본 해시와 비식별 사본 해시를 각각 확인할 수 있습니다. 공개된 사본의 바이트는 사본 SHA-256으로 검증합니다.

Sprint 4.1 게시 전후 운영 DB와 기존 증적 파일 60개의 해시가 일치했습니다. [공개 저장소 파일 매니페스트](../PUBLIC_MANIFEST.json)는 공개 스냅샷의 파일 크기와 바이트 SHA-256을 기록합니다.
